## Memulai integrasi

Integrasikan aplikasi Anda dengan Emplicon API dalam beberapa langkah.

### Langkah 1: Daftar & dapatkan kredensial

1. Daftar di [app.emplicon.com/register](https://app.emplicon.com/register)
2. Verifikasi email (OTP akan dikirim)
3. Login ke [Dashboard](https://app.emplicon.com)
4. Di Settings, buat **API Token** untuk autentikasi

### Langkah 2: Autentikasi

Emplicon API menggunakan Bearer token. Tambahkan header:

```
Authorization: Bearer <API_TOKEN>
```

### Langkah 3: Panggil endpoint

Contoh request ke API:

```bash
curl -X GET "https://api.emplicon.com/api/v1/employees" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
